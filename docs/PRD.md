# PRD — MagicSquare_xx (4×4 부분 마방진)

## 1. 배경

프로그래밍 수업에서 **4×4 부분 마방진(빈칸 2개)** 과제를 풀 때, 학생이 행·열만 맞추고 **10선(행·열·대각선) 중 일부 검증을 누락**하여 약 20분을 추가로 소비한 사례가 있다(Mom Test).

### Mom Test 증거
1. 「지난주 OO 과제에서」
2. 「빈칸 2개 넣고 행·열·대각선 합 맞췄는데」
3. 「대각선 하나를 빼먹어서 20분 날렸다.」

### 진짜 문제 (한 문장)
**지난주 OO 과제에서 빈칸 2개를 채운 뒤 행·열 합은 맞췄지만 10선(행·열·대각선) 중 대각선 하나를 검증에서 빠뜨려, 틀린 상태를 끝까지 못 잡고 약 20분을 추가로 썼다.**

본 PRD는 **"10선=34 판정을 빠짐없이·기계적으로 수행"** 하는 것을 1차 목표로 한다.

## 2. 목표

- 4×4 격자(빈칸 2개)에 대해 **10선 합이 34인지** 검증한다.
- 실패 시 **어느 줄(행/열/대각선)** 이 깨졌는지 식별한다.
- 빈칸 좌표 탐색 및 후보 값에 대한 판정을 제공한다(Logic Track).

## 3. 비목표

- 완성된 PyQt 상용 앱 · 배포
- 3×3 / 5×5 / 마방진 자동 생성
- ECB 분류·슬라이드 설계만으로 "문제 해결" 처리
- 세션 3에서 Domain GREEN·UI 구현 완료

## 4. 사용자

- **Primary:** 프로그래밍 수업에서 4×4 부분 마방진(빈칸 2개) 과제를 받은 **학생** (손으로 빈칸을 채우고 행·열·대각선 합을 맞춤)
- **Secondary:** TDD/ECB 학습자 (Cursor 워크플로 실습)

| 규칙 | 설명 |

| R-01 | 격자는 4×4 |
| R-02 | 셀 값: `0`(빈칸) 또는 `1..16` |
